# 山痕 · Mountain Mark

一个原创的单机 3D 攀岩游戏可玩原型，用 Godot 4.7.2 制作。

从松风岩脚出发，沿 72 米风脊逐点攀登，在岩台休息、在安全锚点保存，最终翻上山顶。低多边形暖色岩壁与冷色群山、环境风声、呼吸与攀爬动作共同构成一段安静的登山旅程。

## 直接开始

- **推荐：双击 `build\MountainMark.exe`。** 已包含引擎与资源，不需要打开编辑器。
- `开始游戏.bat`：通过 D:\tools\Godot-4.7.2 中的 Godot 运行当前源项目。
- `编辑项目.bat`：用指定 Godot 打开工程；也可导入 `project.godot` 后按 F6 / F5 运行主场景。

整个 `build` 文件夹一起保留：入口程序、MountainMark.pck 与 engine 子目录互相依赖。

## 操作

| 按键 | 行为 |
|---|---|
| 鼠标左键 / 右键 | 对准可达岩点按住，准备左手 / 右手；双区就绪后松开抓握 |
| W / ↑ | 观察并标记建议岩点；实际抓握由鼠标完成 |
| A / D | 按住向左 / 右移动重心，将白针移入目标绿区 |
| 空格 | 使用镁粉恢复握力；每段 3 次、冷却 7 秒，安全锚点补满 |
| R | 用安全绳返回最近锚点 |
| Esc | 暂停或继续 |
| M | 开关声音 |
| F11 | 切换全屏 |

每次抓握都有两个判断：先按住鼠标，再用 A / D 把重心白针移进绿区；蓄力白针来回摆动，等两个白针都在绿区时松开鼠标。准备最多 4.5 秒；高处的目标窗口更窄，远距离抓点更费力。

松手时机或重心不对会失手、消耗握力；连续三次失手，或握力耗尽，会触发安全绳并回到最近锚点。金色岩点可自动休息，安全锚点保存进度并补满镁粉。脚部由角色自动寻找支撑。

## 本版本内容

- 一座完整的原创山体，71 个抓点、备选落手点、分段休息台与安全锚点。
- 程序化角色、分段肢体关节动画、伸手抓握、交替蹬腿、重心摆动、呼吸、镁粉粒子、动态安全绳。
- 蓄力时机与重心配合的双条件抓握、有限镁粉补给、连续失手保护、高处递增难度。
- 四阶段攀登、中文操作手册、暂停、音效开关、窗口与全屏。
- 本地自动存档；登顶翻身站立与举臂、镜头拉远、专属音乐、成绩统计和「群山之上」「一气呵成」记录。
- 无联网功能；几何美术与音效均由本项目生成。

这是完整可走通的短路线原型，采用辅助落脚与程序化动作；可在此基础上扩展自由选脚、多条长路线、体力/装备系统及更精细的角色资产。

## 文件与数据位置

所有项目文件位于 **M:\NewGames\MountainMark**。启动器会将 APPDATA、LOCALAPPDATA、TEMP、TMP 指向游戏目录内的 `.runtime`，游戏存档与日志也在该处。

- 源工程存档：`.runtime\save.json`
- 独立版本存档：`build\.runtime\save.json`
- 源工程与独立版本分别保存进度。
- scripts/main.gd：流程、摄像机、输入、存档。
- scripts/climber.gd：人物、动作、体力、绳索。
- scripts/world.gd：山体、远景、抓点和平台。
- scripts/hud.gd：中文界面与抓点指示。
- scripts/audio.gd：声音混音与事件音效。
- tools/generate_audio.gd：原创音效生成工具。
- qa/：逻辑检查、全路线测试与实际渲染截图。

中文字体来自本机已安装的微软雅黑，作为此本地版本的显示资源；引擎来自用户指定的 Godot 安装。

## 验证

验证记录位于 qa/：包括脚本解析、主场景输入/暂停/存档/登顶回归、路线测试与实际渲染截图。双条件抓握版本需配合对应版本的测试结果查看。

重新打包可运行 tools/build.ps1；它会导入资源、导出 PCK、复制指定引擎并编译本地启动器，所有输出仍在本项目目录。


### 0.2.1 跌落提示

跌落后会暂停攀登并显示「这一步，没能抓稳。」，说明触发原因和返回地点。按 Enter 或点击按钮后，才返回最近的安全锚点；尚未抵达锚点时返回山脚。主动按 R 返回使用单独的提示文案。

## 从 GitHub 获取完整工程

此仓库包含源码、素材、测试脚本、截图和可直接启动的 Windows 版本。引擎、字体及 PCK 资源包通过 Git LFS 保存。克隆前安装 Git LFS，随后运行：

```powershell
git lfs install
git clone https://github.com/twogold-design/MountainMark.git
cd MountainMark
git lfs pull
```

双击根目录的 `一键启动游戏.bat` 即可运行。运行时数据会在本地自动创建；个人存档、Godot 缓存、临时日志不纳入版本控制。
