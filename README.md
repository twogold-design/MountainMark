# 山痕 · Mountain Mark 0.3.2 — 重心联动

使用 Godot 4.7.2 制作的原创单机 3D 攀岩游戏。选择山路、调整支撑脚和重心、把握抓握时机，在松林、峡谷与雪岭中登顶。

## 一键开始

双击根目录 **`一键启动游戏.bat`**，或运行 **`build\MountainMark.exe`**。独立版已包含引擎与资源，整个 build 文件夹需要一起保留。

- `开始游戏.bat`：运行源工程，使用 `D:\tools\Godot-4.7.2` 的 Godot。
- `编辑项目.bat`：打开 Godot 编辑器。
- 所有源码、素材、构建产物、运行存档和临时文件均保存在本项目目录内。

## 重心联动（0.3.2）

A / D 现在实际移动身体与肩膀，选定支撑脚也会影响站姿。可达性按当前肩膀到目标岩点的实际距离更新：原先略远的岩点，可以通过向目标侧移重心进入一步可达范围；姿态也影响预计握力消耗。该范围包括连续落脚、蹬腿推进和最后伸手，不代表单条手臂长度。

读线时，青圈表示当前至少有一只手可达，金圈表示需要先移重心。两类目标都可以按住鼠标准备，HUD 会提示是否已进入范围及预计握力消耗。观察辅助线从推荐手的真实肩膀位置连向目标；A / D 始终对应岩壁左右，转动镜头不会改变方向。更新说明见 `docs/UPDATE_0.3.2.md`。

选脚卡以并列的 **Q 左脚 / E 右脚** 显示当前支撑；选中后明确提示「左脚踩稳 · 右脚可移动」或相反状态，角色支撑脚下出现光环，静止与准备时脚边有对应标签。当前动作行显示近点引体、踩点蹬伸、侧身横渡、远点跃抓或折膝侧伸：先选支撑脚，再移重心，最后蹬腿伸手，脚与手的发力顺序通过动作呈现。

折膝（drop knee）表现为脚尖转动、膝盖向内下方落下、转髋贴墙后用同侧手侧伸。Q 左脚配左手、A 左移重心，或 E 右脚配右手、D 右移重心（左键自动选手，右键用另一手），向合适的同侧上方岩点出手时自动衔接。转髋准备会改变实际肩距，较高的正上方岩点保留「远点跃抓」动作。侧伸与跃抓分别实现，手臂长度仍保持固定。

正常攀爬改为连贯蹬身、一次伸手抓牢，另一只手稍后跟上；手掌沿离墙弧线移动，到点后停稳。少量动作会出现一次短暂探点，概率约 8%，首步与连续两步不触发，耗时和体力消耗与普通动作相同。

脚部也改成整步连续换位：自由脚先抬起，支撑腿随蹬身平滑跟进，每只脚沿一条完整轨迹落定。自动落脚不会在一步内反复切换承重侧；抓牢后直接进入待发站姿，不再补抬一次自由脚。折膝的外摆、踩高与内扣也放缓衔接。

较远岩点会在踩稳蹬起时响起短促发力声。握力低于 35 时开始轻喘，越疲劳越急促，恢复到 42 后停止；到达休息平台会停止急喘，响起柔和提示音，握力面板显示恢复量与「缓过来了」。暂停、手册和静音会停止人物声音。

每次手掌实际抓到目标岩点时播放抓握声，包含贴岩轻碰、抓紧摩擦和少量细碎砂石尾音。六个样本采用不同的软掌、掌根指压、三指滚动、粉尘擦拭、双段摩擦和干岩碎屑，轮换时避免相邻重复。播放基准音量下调 4.5 dB，并加入轻微力度与音高变化；小抓点和湿点略有音色变化，抓握、发力、喘息与休息音分别衔接。

## 美术细化（0.3.1）

岩壁、岩块与远山已改用更细的连续网格和平滑光照，配合岩层细纹、软边云雾与流动水面；松树换成细针叶枝簇，角色增加织物、缝线和装备细节。截图和验证见 `docs/UPDATE_0.3.1.md`。

## 三条路线

| 路线 | 高度 | 玩法与场景 |
| --- | --- | --- |
| 松风岩脊 | 72 米 | 晨光松林、营地装备、岩台与路标，熟悉交替用手和分支取舍 |
| 回声峡谷 | 90 米 | 青灰湿壁、双瀑布、流水与蕨类；需要选择支撑脚的横渡，镁粉处理湿滑 |
| 云上孤峰 | 108 米 | 雪岩、冰挂、云海与飘带；观察阵风，等待风弱再出手 |

每条主路线都有三个分岔：**青色绕行**更长，但中途有休息岩台；**橙色捷径**步数更少，以小抓点连续通过，更消耗握力。休息处分岔草图显示两种走法。每条路线沿两种分支共可找到 6 份山路记录。

路线逐步开启：完成松风岩脊开启回声峡谷，完成回声峡谷开启云上孤峰。旧版登顶记录可开启峡谷。

## 两种模式

- **登山旅程**：锚点存档，休息恢复握力，探索分支与笔记。
- **极限登顶**：完成对应路线的旅程后开启。每段只有 2 次镁粉，中途只在半山有安全锚点；保留休息台。独立记录成绩，不覆盖正在进行的旅程存档。

## 操作

| 操作 | 用途 |
| --- | --- |
| 鼠标左键 / 右键按住岩点 | 左键自动选手（直线上攀优先交替、侧向顺手），右键用另一手；实际可达且双区就绪后松开 |
| A / D | 沿岩壁左 / 右移动身体与肩膀，改变实际距离；抓握时进入重心绿区 |
| 鼠标中键拖拽 | 抓握前旋转读线镜头，查看推荐手肩膀与目标岩点的关系 |
| Z / X | 左右旋转读线镜头；Q / E 仍用于选择支撑脚 |
| Q / E | 选择左 / 右支撑脚；侧栏高亮和脚下光环显示踩稳一侧，另一脚可移动 |
| W / ↑ | 标记建议岩点，仅观察，不会自动攀登 |
| 空格 | 使用镁粉，恢复 10 握力并提供 18 秒湿壁保护；冷却 7 秒 |
| R | 用安全绳主动返回锚点 |
| Esc | 暂停 / 继续，或关闭日志与手册 |
| M / F11 | 声音开关 / 全屏 |

抓握准备上限 4.5 秒。远点、跨手和连续同手更费力。小抓点停留比普通岩点耗体更快；湿壁增加消耗，镁粉可暂时消除湿壁惩罚。强阵风时不能安全出手，先看飘带、听风声，等待风弱再开始准备。

按 W 标记目标后，使用中键拖拽或 Z/X 读线；界面会显示肩膀到目标岩点的辅助线、推荐手和岩壁坐标下的重心方向提示。按「先选支撑脚 → 移重心 → 蹬腿伸手」操作：Q / E 选脚，A / D 移近目标，左键自动选手或右键用另一手，按住准备，等可达且双区就绪后松开。开始抓握后镜头锁定；即使重心白针看似进区，实际距离仍未达标时也会提示「尚未可达」，需要继续调整姿态后再松手。

连续 3 次失手或握力耗尽，会显示失败原因并冻结攀爬，按 Enter 或按钮后才返回。金色岩点可休息，安全锚点补满镁粉。横渡角色执行选脚落稳、蹬起、伸手的顺序，膝盖保持向岩壁弯曲。

## 登顶与收藏

三条路线有各自的山顶陈设与结束文案。登顶后先留 4 秒欣赏风景，再展示成绩与纪念章。

- 登山日志按路线和模式记录首次完成日期、完成次数和最好成绩。
- 收集 2 / 6 份山路记录可分别解锁松林绿 / 冰川蓝服装与背包配色；默认落日橙。
- 零跌落、保留镁粉、走全两侧分支、登上云峰与完成极限模式都有纪念章。
- 每次完成在本地留下文字纪念卡；结算页可保存带风景的 PNG 纪念卡。
- 旅程存档独立于极限成绩；支持退出后从已保存锚点继续。

## 文件位置

- 源码：`scripts/routes.gd` 路线数据；`main.gd` 流程、规则与存档；`world.gd` 场景；`climber.gd` 角色；`hud.gd` 界面；`audio.gd` 声音。
- 源工程运行数据：`.runtime/`。
- 独立版运行数据：`build/.runtime/`。两个版本的存档分别保存。
- 纪念卡：相应运行数据目录下的 `postcards/`。
- 自动化验证与截图：`qa/`，验证说明见 `qa/V3_VERIFICATION.md`。

旧版途中存档的岩点布局已变化，继续时安全返回营地；原登顶次数、最佳成绩与攀登统计保留，界面会说明迁移情况。

## 重新构建

运行 `tools/build.ps1`，会导入资源、导出 PCK、复制引擎并编译启动器。所有输出继续位于本项目目录。

## 获取仓库

仓库使用 Git LFS 保存引擎、字体及 PCK：

```powershell
git lfs install
git clone https://github.com/twogold-design/MountainMark.git
cd MountainMark
git lfs pull
```

个人存档、编辑器缓存、临时日志不进入版本控制。几何场景和声景由项目生成；中文字体使用本机微软雅黑，Godot 引擎来自用户指定的安装目录。
