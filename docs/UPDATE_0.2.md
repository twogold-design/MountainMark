# 0.2 攀登操作更新

## 实际玩法

- W / ↑ 只标记建议岩点，不再攀升。
- 对准岩点按住鼠标左 / 右键，分别用左 / 右手准备。
- 按住 A / D 移动重心白针，使其进入绿色目标区。
- 等蓄力白针也进入绿区，松开原先按住的鼠标键抓稳并拉起身体。
- 普通单击、重心未稳、错过时机或悬挂超过 4.5 秒均会失手；每次扣握力，连续 3 次触发安全绳保护。
- 距离更远、跨过身体出手、连续使用同一只手都更费力；高处的判定窗口更窄，并有小幅阵风扰动。
- 每段携带 3 份镁粉，安全锚点补满。休息点仍自动回复握力。
- 暂停或切出窗口会取消未完成的抓握，避免返回时误操作。

## 角色动作

膝盖极向量从朝背包改为朝岩壁，减少左右外翻，脚尖朝墙。攀升拆成短跨步，先抬脚落位、让另一只脚支撑，再蹬腿抬起身体；大小腿保持固定长度。登顶时站直，双脚落在平台。
