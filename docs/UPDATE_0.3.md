# 0.3 远行更新

## 交付范围

三座山（72/90/108米）、每座三个分岔、三种模式、三个短挑战、关键横渡选脚、湿壁/小抓点/阵风、18份山路记录、三种服装、登山日志与本地纪念卡。

路线以明确有向边连接，防止玩家因为抓点距离较近而跳过横渡或分支难点。金色休息点、带安全旗的锚点分别承担恢复和存档/补给职责。极限模式保留休息点，但减少锚点和镁粉。

## 操作设计

保留鼠标抓握＋A/D重心，不增加常规攀爬负担。仅特定横渡需要Q/E指定支撑脚，界面在出手前明确提示。角色动画按选脚、落地、蹬起、伸手组织，固定腿长并保持膝盖向墙。

小抓点通过增加停留消耗催促连贯行动；湿壁通过额外抓握与停留消耗促使选择镁粉或绕路；阵风有连续可见可听预警，风弱时可通过，没有随机失败判定。

## 场景表现

松林晨光配鸟鸣，峡谷双瀑配流水，雪岭云海配阵风。营地、休息岩台、山顶、路标与收藏物件均有环境细节，程序化低多边形风格一致。短挑战按高度减少装饰密度。

## 进度与奖励

旅程是可续攀模式。挑战、极限仅更新独立成绩和收藏，不覆写活动旅程。首次登顶依序解锁山体，完成对应路线开启极限。外观由探索/登顶解锁，没有永久体力数值升级。

旧版进度保留统计但不能沿用旧抓点编号；界面解释安全迁移到营地。存档和纪念卡写入启动器指定的M盘运行目录。
