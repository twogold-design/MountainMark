# 山痕 Mountain Mark · 玩法与声音设计

一款原创单人攀岩体验：从风中的营地攀上一段 72 米花岗岩壁，以身体的伸展、抓握与摆动表现高度，抵达金色峰顶。氛围参考高山攀登的安静与专注；不使用其他游戏的人物、地图或素材。

## 完整体验

1. 营地提供操作提示，让玩家观察由暖色岩点组成的上行路线。
2. W／上方向键观察建议落点；对准可达岩点按住鼠标左、右键准备对应手。A／D 调整重心，使重心指针进入目标绿区；当来回摆动的蓄力指针也进入绿区时，松开鼠标完成抓握。角色的四肢、背包与绳索跟随动作，脚部自动寻找支撑。
3. 每次攀爬消耗体力，远点更费力；金色休息岩点回复体力，安全锚点保存高度并补满 3 次镁粉。空格用镁粉恢复握力，有 7 秒冷却；R 返回最近安全点，Esc 暂停。
4. 准备抓握最多持续 4.5 秒，超时或任一条件未对准便失手、消耗体力。连续三次失手或体力耗尽时由绳索保护并回到安全点。失误意味着重新规划这一小段路线，保留已经完成的攀登进度。
5. 海拔、休息区与风景变化标记进程。接近峰顶时，画面逐渐温暖，抵达后角色庆祝，展示攀登记录并播放专属音乐。

## 节奏原则

- 抓握分为观察、准备、调整重心、把握时机、动作兑现。成功后一次伸手约 0.7 秒，让操作结果具有身体重量。
- 初段蓄力容差约 ±0.16，随高度缩至约 ±0.10；重心容差由约 ±0.30 缩至约 ±0.20。HUD 精确读取当前目标与容差，绿区与实际判定一致。
- 中下方的双条仪表分别显示蓄力与重心目标、白色指针、对准文字状态和倒计时；双条件满足时提示松开。
- 每段攀登包含侧向转移与稳定的休息点，避免连续机械点击。
- 沉浸感来自真实的身体反馈：手掌落点、脚部支撑、重心摆动、绳索牵引及近距离摩擦声。
- 登顶的成就感来自一路可见的高度积累与最后的视野、动作、音乐共同变化。

## 原创声音

全部声音通过项目内 tools/generate_audio.gd 离线生成，不依赖下载、外部服务或其他作品录音。

| 声音 | 设计 | 触发 |
| --- | --- | --- |
| 风声 | 滤波噪声与缓慢阵风，循环边缘平滑衔接 | 开始后持续，随海拔略增强 |
| 远处和声 | 稀疏泛音、缓慢包络、轻微频率漂移 | 在风声下低音量循环 |
| 岩石抓握 | 短促低频触碰与粗糙摩擦，随机轻微变调 | 每次有效抓握 |
| 补粉 | 柔和粉末与布料摩擦 | 补粉成功 |
| 安全绳 | 短暂空气移动与柔和低频回弹 | 跌落 |
| 呼吸 | 双段滤波气流，仅在活动后出现 | 攀爬后间歇触发 |
| 休息点 | 短小上行音程 | 到达安全高度 |
| 登顶 | 20 秒渐进和声与疏朗旋律，风声退后 | 首次到达峰顶 |

音效均为 22050 Hz、16-bit PCM WAV；离线生成后游戏无需现场合成。主音量谨慎，静音同时停止动作与音乐声，环境声平滑恢复。声音接口由 scripts/audio.gd 暴露并由主场景调用。
