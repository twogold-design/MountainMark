## 1. 产品概述

《山痕》是一段以“专注地向上”为核心的单人攀岩旅程。三条山路依次为 72 米松风岩脊、90 米回声峡谷和 108 米云上孤峰。玩家选择绕行或捷径，点住目标朝反方向回拉，看到绿色提示后松手；角色帮助选脚和站稳，玩家可手动微调，在岩台和安全锚点恢复后继续登顶。

游戏的主要乐趣来自三个连续动作：选择下一处岩点、用身体重心稳定伸手、以鼠标回拉长度和角度直接控制落点并松手抓握。角色动画、呼吸、风声、安全绳和逐渐展开的山景共同把“按键判断”转化为“身体正在攀登”的感受。

### 1.1 玩家承诺

玩家每次操作都应回答一个清晰的问题：**我是否能在当前握力和身体姿势下，稳稳抓住下一处岩点？**

玩家应当获得以下体验：

- 看得懂路线，知道哪些岩点可达、哪些岩点值得休息。
- 失手后能理解原因，并能用下一次尝试修正。
- 高度、风景和音乐随进度发生变化，登顶具有明确的情绪回报。
- 失败会增加压力，但不会抹掉已经抵达的安全锚点。

### 1.2 非目标

- 不做战斗、敌人、解谜或联网竞争。
- 不要求玩家管理复杂装备栏、真实绳结或自由布置保护点。
- 点住目标时自动选择所需支撑脚，Q/E 可手动切换；具体落脚自动执行，无需逐个控制脚尖。
- 不追求长时间刷取资源，单次完整攀登应保持在短途、集中注意力的范围内。

## 2. 体验结构

### 2.1 一局流程

```mermaid
flowchart LR
    A[营地菜单] --> B[开始或继续攀登]
    B --> C[观察可达岩点]
    C --> D[按住鼠标选择左手/右手]
    D --> E[自动选脚找稳，朝反方向沿淡线回拉]
    E --> F{落点与提示变绿?}
    F -- 否 --> O[调整回拉，等待身体找稳]
    O --> F
    O -- 轻点或极短回拉松手 --> C
    O -- 有效回拉条件不足时松手或超时 --> G[失手，握力下降]
    G --> H{连续失手三次或握力耗尽?}
    H -- 否 --> C
    H -- 是 --> I[安全绳返回最近锚点]
    I --> C
    F -- 是 --> J[松开鼠标，完成攀爬]
    J --> K{休息点或安全锚点?}
    K -- 是 --> L[恢复握力/保存进度]
    K -- 否 --> C
    L --> C
    C --> M{到达峰顶?}
    M -- 否 --> C
    M -- 是 --> N[翻身站立、登顶记录、庆祝音乐]
```

### 2.2 核心循环

1. **观察：** 查看当前可达岩点、距离、方向和休息标记。
2. **计划：** 在稳妥的近点、较快的远点和休息点之间做选择。
3. **准备：** 左键或右键点住目标，决定使用哪只手；角色自动选择所需支撑脚并逐渐找稳。
4. **回拉：** 朝出手反方向沿淡线拖拽，长度控制射程、角度控制方向；常见小误差由连续辅助平滑修正。
5. **看绿：** 等落点与提示变绿即可松手，Q/E 和 A/D 可按需微调；静止不增加力度，极短回拉松手可取消。
6. **兑现：** 松开对应鼠标键；命中后角色落脚、蹬腿并抓住拖拽决定的实际触点，落空则伸手后回收。
7. **恢复：** 在休息点停留，或在锚点使用安全绳回退后重新规划。

## 4. 操作与交互规则

| 输入 | 行为 | 设计目的 |
| --- | --- | --- |
| 鼠标左键点住目标、向后拖拽/松开 | 使用左手，回拉长度控制射程、角度控制方向 | 让手势直接决定实际落点与准确度 |
| 鼠标右键点住目标、向后拖拽/松开 | 使用右手，按预计落点瞄准后出手 | 鼓励左右手交替，减少连续同手消耗 |

| Q / E | 手动切换左/右支撑脚，点住时自动选择所需支撑 | 保留脚部控制，降低初次抓握的操作负担 |

| Z / X | 左右旋转读线视角 | 不使用鼠标拖拽时的键盘替代方案；Q / E 保留给支撑脚选择 |
| 空格 | 使用一次镁粉 | 以有限资源换取握力缓冲 |
| R | 沿安全绳返回最近锚点 | 主动止损并重新规划 |
| Esc | 暂停/继续 | 暂停时取消未完成抓握 |
| M | 开关全部声音 | 支持安静游玩 |
| F11 | 窗口/全屏切换 | 适配不同游玩环境 |
| 【·／`】（Esc 下方、数字 1 左侧） | 精简/恢复界面及辅助标记，保留基础操作提示 | 让玩家自行选择界面辅助与沉浸感 |

### 4.1 抓握状态机

```text
待机
  └─ 左/右键点住候选岩点 → 拖拽瞄准中
       ├─ 向出手反方向回拉 → 长度与角度更新预计落点
       ├─ 轻点或极短回拉后松手 → 取消，不计失手
       ├─ 松开且命中、站稳、实际可达及岩段条件满足 → 攀爬动画 → 抓住实际落点
       ├─ 松开但预计落点偏离或条件不满足 → 失手
       ├─ 超过 7 秒 → 失手
       ├─ 握力归零 → 跌落保护
       └─ 视口尺寸改变/切出窗口/暂停/打开手册 → 取消拖拽，回到待机
```

一次抓握最多准备 7 秒，没有最低准备时长。回拉短于 `max(10 像素, 当前理想回拉长度 × 0.20)` 时松手视为取消，不累计失手、不追加扣握力，已产生的悬挂消耗不退回。单纯按住不会增加力度；常见长度和角度误差得到辅助，明显偏离仍会失手。绿色提示合并命中、身体、可达和岩段条件，让玩家以一次回拉完成主要操作。

### 4.2 读线视角

玩家按 W/↑ 标记建议岩点后，可以在未抓握、未移动时用鼠标中键拖拽或 Z/X 旋转镜头。辅助线从推荐手的实际肩膀连到目标。青色圈表示当前可达，金色圈表示移重心后可达；HUD 展示推荐手、A/D 移动方向与预计握力消耗。

读线视角只改变观察角度和提示，不改变身体可达范围、实际重心目标或握力消耗。点住目标后镜头完全冻结，中键和 Z/X 不再改变镜头，拖拽按该固定视角映射到岩壁。A/D 与选脚仍会改变真实肩膀位置，预计轨迹从更新后的肩膀投影起点计算；调整视口大小、暂停、失焦或打开手册会取消本次手势。

## 5. 抓握判定与数值

### 5.1 辅助拖拽与真实落点

左 / 右键点住目标后，朝出手反方向沿淡线回拉，看到绿色提示即可松手。手势以按下位置为锚点，长度和角度决定原始落点，目标附近的常见误差得到连续修正。力度槽显示回拉比例与参考力度；鼠标静止不自动增力，收短回拉会减力。映射倍率由 2.0 降至 1.5，每像素引起的射程变化降低 25%，便于慢慢调整。

先保留固定镜头与岩壁平面的原始反投影，再计算辅助后的实际落点：

```text
回拉上限 = max(80 像素, 视口短边 × 0.30)
反向回拉向量 = clamp_length(按下位置 - 当前鼠标位置, 回拉上限)
力度 = 反向回拉向量长度 / 回拉上限
岩壁起点 = (当前肩膀 x, 当前肩膀 y, 目标岩壁平面 z)
出手屏幕位置 = 镜头投影(岩壁起点) + 反向回拉向量 × 1.5
原始落点 = 镜头穿过出手屏幕位置的射线与目标岩壁平面的交点
理想回拉长度 = 屏幕中岩壁起点至目标的距离 / 1.5
辅助评分 = hypot(回拉偏角 / 30°, (回拉长度 / 理想回拉长度 - 1) / 0.40)
辅助权重 = 0.88 × (1 - smoothstep(0.60, 1.25, 辅助评分))
                  × smoothstep(6, 14, 回拉像素长度)
预计落点 = lerp(原始落点, 目标中心, 辅助权重)
落点误差 = 预计落点与目标中心的三维距离
```

辅助权重随误差连续衰减，不会硬切换到中心；常见小误差获得帮助，明显反向、过强或过短的拖拽仍会落空。界面用淡色小点保留原始落点，以主预测点显示修正后的实际落点，并提供较宽的回拉方向引导。辅助不改变以下世界容差和真实可达判定。

| 岩点类型 | 命中容差 |
| --- | ---: |
| 普通 | 0.18 米 |
| 小抓点 | 0.11 米 |
| 湿壁 | 0.14 米 |
| 休息点 | 0.22 米 |

轻点或极短回拉按 4.1 的规则取消。有效出手时，修正后的预计落点必须处于容差内，且最终触点可由到达姿态的真实手臂长度触及；手掌落在该实际位置，动作节点仍由选中岩点决定。明显落空时，手沿错误方向在臂长内进行约 0.50 秒短探空再回收，不播放成功接触音、不更换当前岩点或推进身体。

松手仍须满足正确支撑脚、当前实际可达、重心绿区和风况条件；阵风岩点要求风力低于 0.72。点住时自动选脚，身体渐进找稳；绿色提示表示这些条件已满足，Q/E 与 A/D 可手动微调。悬挂上限为 7 秒，准备额外消耗每秒 1 握力。

### 5.2 重心白针

点住目标时，若岩段指定支撑脚就自动选中该脚；未指定且尚无选择时，选中出手侧脚。准备中未按 A/D 时，身体按 `clamp((目标重心 - 当前重心) × 5, -1.8, 1.8)` 的速度渐进找稳；A/D 手动输入优先，Q/E 仍可切换支撑。阵风继续影响姿态。A/D 使骨盆横移最多约 0.32 米，并改变肩膀位置与贴墙程度；身体显示、肩膀查询和判定共用同一姿态。

目标重心根据“所选肩膀在岩壁横向上对齐目标”求出，限制在 -0.90 到 0.90；不再添加与岩点无关的高度正弦偏移。方向提示始终以岩壁为参照，旋转镜头不改变方向或距离判定。

当前肩膀到目标距离必须在动作预算内，才能松手成功。预算由 0.715 米的最终伸手与 2.10 米的连续落脚推进构成；要求支撑脚的岩段在正确选脚后增加 0.05 米。可读候选保留在界面中，允许先选中、再移重心到位，而不是把暂时够不到的点直接隐藏。

- 起始窗口约 ±0.30。
- 峰顶附近约 ±0.20。
- 远距离抓点额外缩小约 0.025。
- 阵风会扰动身体，自动找稳持续修正，玩家可用 A/D 微调。

### 5.3 成功质量与握力消耗

未命中或最终触点不可达时质量为 0；命中后，抓握质量继续按辅助修正后的实际落点误差与身体稳定程度计算：

```text
命中精度 = 1 - clamp(落点误差 / 命中容差, 0, 1)
身体稳定 = 1 - clamp(|当前重心 - 目标重心| / 重心窗口, 0, 1)
抓握质量 = clamp(命中精度 × 0.85 + 身体稳定 × 0.15, 0, 1)
```

落点越接近岩点中心，命中精度越高，身体稳定提供其余质量。精准挑战保留“连续 5 次质量不低于 0.65 并抵达终点”的要求，玩家需直接调整回拉长度与角度提高准确度。一次移动的基础消耗为：

```text
消耗 = 4.0
     + max(0, 岩点间距 + 当前肩至目标距离 - 中立肩至目标距离) × 2.2
     + 跨过身体出手额外 2.5
     + 连续使用同一只手额外 1.5
     + (1 - 抓握质量) × 3.0
     + 岩面附加消耗
     - 支撑到位的蹬腿节省（最多 0.45）
```

同一只手、同一目标和同一抓握质量下，把身体移向目标会缩短实际肩距、减少消耗；反向倾身则增加消耗。支撑脚合格且身体移到位时，可以借助腿部发力再节省最多 0.45 握力。路线原本的移动成本作为基线，使已有长路线和极限模式仍有合理容错。小抓点附加 0.3，未受镁粉保护的湿壁附加 4.0。

### 5.4 握力与恢复

| 行为 | 握力变化 |
| --- | ---: |
| 初始/返回锚点 | 恢复至 100 |
| 非移动攀爬待机 | 每秒约 -0.38 |
| 按住岩点准备 | 在待机消耗之外，每秒额外约 -1.00 |
| 失手 | 额外 -6 |
| 轻点或极短回拉取消 | 不追加消耗，不退回已发生的悬挂消耗 |
| 镁粉 | +10，旅程 3 次、极限 2 次；冷却 7 秒，防湿 18 秒；横渡挑战禁用 |
| 金色休息点 | 停留时每秒约 +23，最高 100 |
| 连续三次失手或握力耗尽 | 触发安全绳 |

休息点是“停留恢复”，锚点是“保存与补给”。两者功能分开，玩家能在路线中途缓慢回满握力，也能在关键节点获得明确的失败保护。

## 6. 失败、回退与存档

### 6.1 失败类型

- **重心没有稳住：** 自动找稳尚未完成或手动偏移，松手时重心未在绿区。
- **力度偏小 / 偏大：** 回拉过短或过长，预计落点未进入岩点容差。
- **方向偏离：** 回拉角度带偏了预计落点，出手未抓到岩点。
- **支撑脚未选稳：** 岩段要求指定支撑脚，松手时 Q/E 选择尚未满足。
- **实际距离未达标：** 当前肩膀尚未移入目标的动作可达预算，或预计触点超出到达姿态的真实臂长。
- **阵风过强：** 阵风岩点的风力仍不低于 0.72，需要等待风弱。
- **悬挂太久：** 超过 7 秒未完成准备。
- **握力耗尽：** 准备过程中或待机时握力归零。
- **主动返回：** 玩家按 R，沿安全绳回到最近锚点。

轻点或极短回拉松手属于取消，不记失手、不追加扣握力，已发生的悬挂消耗保留。其余抓握条件不足时松手或悬挂超时，额外扣 6 握力并累计失手次数。连续三次失手，或握力耗尽，进入跌落提示界面；角色暂停，玩家按 Enter 或按钮确认后再返回。

### 6.2 回退规则

- 已抵达锚点：返回最近锚点。
- 尚未抵达第一个锚点：返回山脚营地。
- 返回后握力恢复至 100，镁粉补满 3 次。
- 已保存的攀登进度、总移动次数、累计失败次数保留。
- 失败提示明确展示触发原因和返回位置，避免“随机惩罚感”。

### 6.3 存档数据

存档位于游戏目录 `.runtime/save.json`，当前记录：

- 最近安全锚点。
- 当前旅程用时。
- 累计跌落次数。
- 已完成移动次数。
- 是否存在未完成旅程。
- 登顶次数。
- 最佳用时。
- 是否完成“零跌落”登顶记录。

存档在抵达锚点、跌落、返回菜单、退出游戏和登顶时写入。测试参数启动时不写入玩家存档。

## 7. 角色与反馈设计

### 7.1 角色动作

角色采用程序化身体，不依赖外部角色资产。准备时，随回拉长度平滑加载膝、肘的发力姿态，手掌和脚部触点保持固定；收短回拉后姿态相应放松，松手后自然衔接到出手动作。一次成功攀爬包含：

1. 领先手伸向拖拽决定、且位于目标容差内的实际触点。
2. 另一只手保持支撑或随后跟进。
3. 领先脚先落位，支撑脚随后移动。
4. 身体与两脚沿协调的连续轨迹推进，自由脚先离墙，支撑腿随蹬起跟进。
5. 背包、四肢、手套、靴子和绳索随身体位置更新。

动作库包含正身蹬起、侧身横渡、屈膝高踩和折膝侧伸，按照目标方向、步幅和支撑脚选择。支撑脚承重，自由脚先找点，随后骨盆推进、手臂伸出；到达新岩点后重心平滑回到稳定姿态。左右支撑脚通过脚下标记、腿部屈伸和 HUD 标签区分。动作中手掌限制在实际手臂长度内，保持原有大小腿长度。

折膝侧伸对应 drop knee：脚尖转动、膝盖向内下方落下，骨盆侧转贴墙，用同侧手向侧上方伸展。Q/E 选择同侧脚、A/D 向该侧移重心时先形成转髋准备，肩膀实际位置随身体变化；准备阶段支撑脚保持原接触。成功出手后先转移支撑、把同侧脚踩高，再内扣落膝、侧伸和还原。自动选择需要手脚同侧、目标向同侧约 0.4 米以上且上移约 0.35–1.6 米，较高的垂直步幅保留高踩动作。伸展收益通过实际肩膀和身体姿态体现，不增加手臂长度。动作依据见 [BMC 折膝教学](https://www.thebmc.co.uk/en/how-to-use-a-drop-knee-when-climbing-video)与 [REI 动作说明](https://www.rei.com/learn/expert-advice/climbing-techniques.html)。

常规动作的蹬身、换脚与伸手保持连贯。每只脚沿贯穿动作的连续轨迹落定，自动支撑在一次移动中保持同一侧；自由脚先离墙，承重脚稍后跟随身体推进，避免重复短促抬落。落手末端已进入选定支撑的待发姿态，抵达后无需补抬自由脚。出手侧沿离墙弧线一次伸向目标，跟随手稍后推进，落手后保持接触。偶发探点的触发概率为 8%，首步和前一步已探点时不触发；中途只进行一次约 0.1 秒的轻微侧探，身体与双脚同步稍停。该变化只影响演出，整步总时长、耗体和成功规则一致。

登顶时角色先拉过岩唇，再把双脚放到平台，最后站直举臂。该演出是玩法完成后的主要情绪奖励。

拖拽落空且尚未触发整段保护时，出手侧手掌沿错误方向进行约 0.50 秒短探空再回收，始终限制在真实臂长内；不触发成功接触音，不推进身体，也不更换当前岩点。

### 7.2 可读反馈

界面显示时，HUD 让玩家同时看到：

- 当前章节和垂直高度。
- 路线竖向进度与锚点位置。
- 握力数值、镁粉剩余次数和当前状态。
- 可达岩点、休息点、锚点和 W 标记的建议点。
- 回拉力度槽、参考刻线、淡色方向引导、出手轨迹与目标容差圈。
- 辅助生效时的淡色原始点、修正后的实际预测点，以及绿色松手提示。
- 身体自动找稳状态、重心条，以及剩余悬挂时间。
- 失手原因、累计失手次数和安全绳触发条件。

信息优先级遵循“当前动作 > 当前资源 > 路线进度 > 叙事装饰”。

玩家可随时用【·／`】精简或恢复界面，包括菜单、暂停、日志、手册、跌落与登顶画面。读线辅助线、候选岩点提示圈和动态高亮、支撑脚光环也一起切换，实际岩点与场景保留。精简时底部仍显示“点住、沿淡线回拉、绿色松手”、Q/E 与 A/D 微调、Esc 暂停及【·】恢复；暂停、跌落、手册和日志改为对应提示。拖拽时保留力度槽与参考刻线、较宽的回拉方向引导、原始点与辅助后的实际预测点、轨迹、目标容差圈、身体状态、悬挂倒计时和绿色松手提示，与完整界面共用同一组件，松手或取消后收起。组件不接收点击或键盘焦点。隐藏界面不改变攀爬、手势、握力、镜头或声音；Esc 暂停和 Enter 跌落重试仍有效，重启默认显示完整界面。

## 8. 视听设计

### 8.1 视觉节奏

- 岩壁使用暖色低多边形花岗岩，抓点使用浅色，休息点使用金色。
- 可达岩点通过环形标记显示，选中点放大并提高发光强度。
- 远景使用冷色群山和云层，随高度增加逐渐打开视野。
- 接近峰顶时色温变暖，旗帜、平台和最终视野成为明确目标。
- 摄像机跟随身体平滑移动，登顶后逐渐拉远，呈现高度变化。

### 8.2 声音触发

| 声音 | 触发 | 作用 |
| --- | --- | --- |
| 风声与远处和声 | 持续播放，随海拔变化 | 建立空间和高度感 |
| 岩石抓握 | 出手手掌实际接近目标触点时，一步一次 | 六个不相邻重复的贴岩、抓紧摩擦与细碎砂石样本；小点更轻细、湿点略低柔，强化落手感觉 |
| 短促发力 | 出手前实际肩膀到目标距离达到本次可达上限的 72%，首次落脚后蹬起 | 两种短呼气声略微变化，远点发力更明显，每步只触发一次 |
| 镁粉 | 使用空格 | 让资源消耗有触觉反馈 |
| 安全绳 | 失手/跌落 | 明确保护介入 |
| 呼吸 | 健康时攀爬后偶尔轻呼吸；握力低于 35 开始喘息，恢复到 42 停止 | 耐力越低，喘息越频繁、略更明显；喘息与发力共用人物声音通道，避免重叠 |
| 休息点提示 | 首次落稳休息台/锚点，登顶单独处理 | 普通平台播放轻柔上行音，锚点保留原提示；握力面板以 4 秒柔光显示恢复量，接近满值显示「缓过来了」 |
| 登顶音乐 | 首次登顶 | 完成情绪释放 |

所有声音由项目内离线生成，静音时停止动作音效和音乐并保留可恢复的环境状态。

平台落稳时立即停止急喘；人物声音在暂停、攀登手册、跌落、菜单和登顶时停止，恢复操作后不补播已错过的发力声。休息音和恢复量提示独立于顶部提示，即使同时发现记录或进入新章节也能看到正向反馈。声音与提示不改变可达性、耗体和体力恢复规则。

## 9. 难度与公平性

难度只通过玩家可理解的身体约束增加，不依赖隐藏随机伤害：

- 远点消耗更多握力，且更容易跨手。
- 高处重心绿区变窄，阵风更明显；不同岩点采用明确的落点容差，小抓点需要更准确的长度与角度控制。
- 连续使用同一只手更费力，鼓励节奏化交替。
- 休息点和锚点按固定节奏出现，玩家可提前规划。
- 失手反馈给出具体原因，三次保护机制避免长时间重复跌落。

辅助设计：W/↑ 提供观察建议，点住时自动选脚、身体逐渐找稳，目标附近平滑修正落点；HUD 以淡线、原始点和实际预测点说明辅助，绿色统一提示可松手。Q/E 与 A/D 保留手动微调，轻点可取消，R 允许主动止损；暂停、切出窗口、改变视口大小或打开手册会取消未完成拖拽。

## 10. 成功标准与验收

一条可交付的玩法版本应满足：

1. 新玩家能理解“点住岩点朝反方向拉，绿色时松手”，知道轻点可取消，并能在自动选脚、站稳和落点辅助下完成基础抓握；Q/E 与 A/D 用于按需微调。
2. 从起点到峰顶存在至少一条连续可达路线。
3. 三条路线的绕行、捷径、三个挑战与极限模式均可用合法输入完成，不发生非法抓点或状态卡死。
4. 失败后能稳定进入提示、确认、返回锚点、继续攀登的完整链路。
5. 锚点保存、继续旅程、登顶统计和最佳用时可在重启后恢复。
6. 暂停、静音、全屏、正常退出、视口尺寸变化、打开手册和窗口切出不会破坏存档或遗留拖拽状态。
7. 登顶演出至少包含翻身、站立、镜头拉远、音乐和记录展示五个反馈层。

建议持续关注的体验指标：

- 首次抓握成功率。
- 第一次到达 18 米锚点所需时间。
- 每个区段平均失手次数。
- 使用镁粉的高度分布。
- 主动返回比例。
- 无跌落登顶比例和最佳用时。

## 11. 后续扩展边界

在不破坏当前核心循环的前提下，可按以下顺序扩展：

1. 增加第二条路线，使用不同的休息点分布和横向转移节奏。
2. 增加“自由选脚”作为高阶模式，保留当前自动脚部作为默认体验。
3. 将镁粉升级为少量装备选择，例如恢复型、稳定型和远距型。
4. 增加练习模式，允许玩家单独练习拖拽落点或重心，不计入正式记录。
5. 增加照片/路线回放，但不引入联网排行榜作为核心目标。

任何扩展都应继续遵守三条原则：下一步看得懂、失误说得清、进度保得住。
