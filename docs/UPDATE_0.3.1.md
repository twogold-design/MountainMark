# 0.3.1 美术细化

这次更新重点减少低细分网格的三角面片感，保持三条路线和全部操作规则。

- 主岩壁改为52列、每0.48米一行的连续网格，共享顶点和平滑法线；移除逐三角随机颜色和直线裂缝贴片。
- 岩块使用细分风化轮廓，周向接缝焊接；营地、岩台与山顶的基岩高度调整，避免穿透表层。
- 远山改为多峰高细分地形，拓宽山肩、平滑雪线；云雾用软边透明材质。
- 石面使用共享512像素无缝噪声、三平面映射、弱分层纹理和微表面起伏；草地与雪地使用独立材质。
- 松树由低面锥体改为枝干与细针叶，针叶合并成单张网格；草和蕨叶更纤细。
- 瀑布改用曲面与软边流动纹理，河流改为连续曲带。
- 角色球面提高到24×12、骨段20面；衣裤背包使用共享128像素织物与微法线，增加缝线、拉链、头盔扣带和鞋底细节。

全部材质和模型由工程本地生成，无需联网下载，不新增外部依赖。通过原一键启动入口运行新版。
