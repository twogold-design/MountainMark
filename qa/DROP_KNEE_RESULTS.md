# 折膝侧伸动作验证

日期：2026-10-22。Godot 4.7.2，版本仍为 0.3.2。

## 动作与操作

折膝侧伸对应 drop knee：通过脚尖转动、膝盖内扣下落和转髋贴墙，以同侧手向侧上方伸展。保留原有高踩，并更名为「屈膝高踩」。参照 [BMC 动作教学](https://www.thebmc.co.uk/en/how-to-use-a-drop-knee-when-climbing-video)与 [REI Drop Knee 说明](https://www.rei.com/learn/expert-advice/climbing-techniques.html)。

- 左侧：Q 选左脚，A 向左移髋，左键出左手。
- 右侧：E 选右脚，D 向右移髋，右键出右手。
- 同侧目标横向约 0.4 米以上、上移约 0.35–1.6 米时自动选用；跨侧、未选支撑、低横渡和高垂直点保留各自动作。
- 准备阶段转髋改变真实肩膀位置，支撑脚保留原触点。动作中先转移承重、外移并踩高同侧脚，再内扣落膝、同侧侧伸、复位。脚部外移和抬高错开发生，膝弯曲平面连续旋转，避免腿轴附近突然翻面。
- 渲染姿态与实际肩距使用同一变换。手臂长度、原有移动计数与指定耗体不变，未给折膝额外距离常量。侧栏、岩面观察和手册加入提示。

`qa/drop_knee_preview.gd` 在独立 Godot 舞台实际渲染左右折膝与普通高踩，各提供正面、背面斜视，单组 37 帧。已检查 `qa/drop-knee-contact.png` 六个时间点和 `qa/drop-knee-preview.gif` 连续动画，确认膝内下落、转髋、侧伸、落手与退出可读，头部与目标没有裁切。原始帧位于忽略目录 `.runtime/drop-knee-frames/`。

`build/MountainMark.pck` 已重新导出并直接运行检查；关闭旧游戏窗口后重新启动即可加载。同包包含降低音量并重新区分的六种抓握声。测试使用隔离目录和 `--qa-capture`，未改写玩家存档。headless 运行有既有 Windows 根证书读取诊断，无脚本或素材加载错误。
