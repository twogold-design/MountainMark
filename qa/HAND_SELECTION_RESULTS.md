# 自然换手与鼠标输入验证

日期：2026-10-22

原因：鼠标左键原先固定映射左手，玩家重复使用左键时绕过了已有的推荐手逻辑。

现在左键采用自动选手：可达性优先，侧向目标用顺手侧，直线上攀优先交替。右键使用另一只手。准备时锁定本次手和起始鼠标键，释放其他键不会触发攀爬。HUD、手册和 README 同步更新。

- `hand_selection_test.gd`：源码与独立包均 70 项通过。连续六次左键产生右、左、右、左、右、左，实际动画及最终手掌接触与选择一致。覆盖横渡、右键覆盖、错误按键释放、取消、重置，以及仅一只手可达时优先可达手。带画面捕获为 71 项通过。
- `automatic-hand-ui.png`：已检查 1280×900 实际界面，正确显示「松开左键 · 右手抓握」，底栏无文字溢出。
- `reach_geometry_test.gd`：23 项通过。真实肩膀范围、支撑脚、重心、镜头方向和恢复判定正常。
- `expedition_v3_test.gd`：显式选手回归 2394 项通过；以 `--auto-hands` 在最终 PCK 中通过同一左键准备/释放路径跑完整路线，3210 项通过，覆盖三座山绕行/捷径、三项挑战、极限及低精度通关。
- `package_reach_smoke.gd`：13 项通过；重新构建的启动器 smoke 返回 0。

环境仍有系统证书读取提示；几何测试仍有既有的退出时资源清理提示，功能断言通过。新换手测试与独立包运行未出现脚本错误。所有测试使用 M 盘隔离数据目录。
